## Описание программы

**Book Tracker** — это GUI‑приложение для управления списком прочитанных книг. Приложение позволяет добавлять книги, фильтровать их по жанру и количеству страниц, сохранять и загружать данные в формате JSON, а также удалять отдельные записи или весь список целиком.

### Возможности:
* ✅ Добавление книг с указанием названия, автора, жанра и количества страниц
* ✅ Фильтрация книг по жанру (Роман, Фантастика, Детектив и др.)
* ✅ Фильтрация по количеству страниц (> 200, > 300, > 500)
* ✅ Сохранение данных в JSON‑файл
* ✅ Загрузка данных из JSON‑файла
* ✅ Удаление выбранной книги
* ✅ Очистка всего списка книг
* ✅ Валидация вводимых данных (проверка пустых полей, числовое значение страниц)

## Примеры использования

### Добавление книги
1. Заполните все поля формы:
   * **Название книги:** «Мастер и Маргарита»
   * **Автор:** «Михаил Булгаков»
   * **Жанр:** «Роман»
   * **Количество страниц:** 480
2. Нажмите кнопку **«Добавить книгу»**.
3. Книга появится в списке внизу окна.
4. Вы увидите сообщение «Книга успешно добавлена!».

### Фильтрация

#### По жанру
1. Введите жанр в поле «Фильтр по жанру» (например, «Роман»).
2. Нажмите **«Применить фильтры»**.
3. В таблице останутся только книги указанного жанра.

#### По страницам
1. Введите минимальное количество страниц в поле «Больше страниц» (например, 300).
2. Нажмите **«Применить фильтры»**.
3. В таблице останутся книги с количеством страниц больше указанного.

#### Комбинированная фильтрация
1. Введите жанр и минимальное количество страниц.
2. Нажмите **«Применить фильтры»**.
3. Отобразятся книги, соответствующие обоим критериям.

#### Сброс фильтров
1. Нажмите кнопку сброса (если есть) или очистите поля фильтров и обновите отображение.

### Сохранение и загрузка
* **Сохранить:** Данные автоматически сохраняются в файл `books.json` при добавлении каждой книги.
* **Загрузить:** При запуске приложения данные автоматически загружаются из файла `books.json`.

### Удаление

#### Удалить выбранную книгу
1. Выберите книгу в таблице.
2. Используйте соответствующую функцию (в текущей версии удаление не реализовано, но можно добавить кнопку «Удалить выбранную»).

#### Очистить всё
1. Для удаления всех книг можно добавить кнопку «Очистить всё» с подтверждением действия.

## Валидация данных

Приложение проверяет:
* Все поля должны быть заполнены (иначе — ошибка «Все поля должны быть заполнены!»).
* Количество страниц должно быть положительным числом (иначе — ошибки «Количество страниц должно быть числом!» или «Количество страниц должно быть положительным числом!»).
* При фильтрации: если ничего не найдено, отображается сообщение «По вашему запросу ничего не найдено».
